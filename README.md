# Magnit Sales Prediction — Drift-Aware Solution Team 003 `6-7`

## Описание решения
Данное решение построено для прогнозирования продаж новых торговых точек сети «Магнит» в условиях значительного дрейфа данных (Data Drift).

### Основные особенности подхода:
1. **Борьба с дрейфом (Drift Mitigation):** 
   - Использование **квантильной регрессии**  для минимизации MAPE и снижения рисков «недоторговок» (under-trading).
   - Оптимизация **весов признаков** (feature weights) через Optuna для снижения влияния нестабильных во времени факторов.
2. **Ансамблирование (Seed Averaging):**
   - Финальный прогноз является средним арифметическим ансамбля из **10 моделей CatBoost**, обученных с разными случайными сидами. Это радикально снижает дисперсию (Variance) прогноза и повышает устойчивость модели на холдоуте.
3. **Feature Engineering:**
   - Созданы относительные показатели плотности спроса и конкуренции: `families_per_competitor`, `attraction_per_square`, `families_x_attraction` и др.
   - Использование логарифмической трансформации целевой переменной.

## Структура репозитория
- `predict.py` — основной скрипт инференса, реализующий предобработку и работу ансамбля.
- `models/` — папка с весами 10 моделей в формате `.cbm` и метаданными признаков.
- `requirements.txt` — список зависимостей.
- `Dockerfile` — конфигурация для сборки контейнера.
- `predictions.csv` — контрольный файл прогнозов.

## Инструкция по запуску

### 1. Сборка Docker-образа
Сборка должна занимать не более 5 минут.
```bash
docker build -t solution .
```

### 2. Запуск инференса
Для работы модели необходимо смонтировать тома с входными данными и папку для вывода результата. Входной файл должен называться `holdout.csv`.

```bash
docker run --rm \
    -v $(pwd)/data/input:/data/input:ro \
    -v $(pwd)/data/output:/data/output \
    solution
```

**Параметры инференса:**
- Вход: `/data/input/holdout.csv`
- Выход: `/data/output/predictions.csv`
